Overview

What is Decepticon?

Decepticon is an open-source autonomous red-team agent with Plan, Red and Blue modes. Its specialist agents support reconnaissance, vulnerability research, exploitation, Active Directory, cloud and related operations. It executes operations inside a sandbox, retains findings in a knowledge graph, and offers a CLI and optional web dashboard. The project also offers a hosted service.

Its maintainers report benchmark results in the repository; these are project-reported figures rather than independently verified performance guarantees.

  • Reconnaissance and vulnerability investigation
  • Exploitation and specialist Active Directory or cloud workflows
  • Evidence preservation, finding review and attack graph exploration
  • Research on agent-driven offensive and defensive security workflows
