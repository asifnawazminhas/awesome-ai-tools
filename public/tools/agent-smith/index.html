Overview

What is Agent Smith?

Agent Smith is an open-source AI pentesting framework designed for both augmented and autonomous authorised security testing. It combines an LLM-driven methodology with 50+ security tools, sandboxed execution, evidence-backed findings, exploit validation, AI red teaming and reporting workflows.

Best suited for

Security use cases

  • Autonomous and augmented penetration testing
  • Web application and API security testing
  • AI and LLM red teaming
  • Exploit validation and evidence collection
  • Security reporting and remediation workflows
