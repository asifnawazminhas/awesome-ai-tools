Overview

What is Orkas?

Orkas is an open-source, local-first desktop AI workspace. Its Commander turns goals into executable plans and coordinates specialist agents for research, coding, data analysis, documents and media tasks. It runs as a desktop application rather than a hosted web service. Model calls and optional connected services may incur additional costs.

  • Coding and automation assistance
  • Data analysis and document workflows
