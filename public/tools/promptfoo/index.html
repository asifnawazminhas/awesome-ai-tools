Overview

What is Promptfoo?

Promptfoo is an open-source CLI and library for evaluating prompts, comparing models, and red teaming LLM-based applications. It supports automated security tests, vulnerability reports, and CI/CD integration. It can run locally, while external model providers may charge for usage.

Best suited for

Suggested use cases

  • LLM application red teaming and prompt injection testing
  • Repeatable evaluations of prompts and models
  • Continuous AI security testing through CI/CD
