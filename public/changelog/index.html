What Changed

12 October 2026

Website v3.0: Typography and Interface Refresh

Introduced a cohesive design layer across the entire directory: improved heading and body typography, responsive navigation, more legible tool cards and capability badges, refined directory filters and tool pages, polished submission forms, accessible focus indicators and consistent dark/light theme controls. Preserved all 42 tools, existing logo, blue-purple colours, URLs, sharing, comparisons and community submission workflow.

12 October 2026

Added Decepticon: Autonomous Red Team Agent

Added Decepticon to Security-Native AI. The open-source project supports autonomous red-team operations, specialist security agents, sandbox execution and evidence-backed workflows. The directory now includes 42 tools: 18 Security-Native AI and 24 General-Purpose AI.

11 October 2026

UI Refresh v2.4: Light Mode Contrast Fixes

Improved light theme readability across homepage search, category cards, tool cards, filters, buttons, submission forms and tool profiles. Preserved dark mode, existing branding, tool data and navigation.

11 October 2026

UI Refresh v2.3: Homepage Discovery Fixes

Restored Featured, Recently Added and Recommended homepage panels by fixing a directory initialisation error and correcting section markup. Added a View all action for the third panel, labelled collection views with accurate counts and clear reset controls. Recently Added sorts globally by recorded addition dates. Personal most-opened tools are ranked only from this browser's local activity, with Recommended Tools shown when usage history is unavailable.

11 October 2026

UI Refresh v2.2: Animation and Directory Sorting

Added subtle, reduced-motion-friendly animation to the homepage orbit illustration. Set A-Z as the default and reset sort, and fixed Recently Added so tools are sorted globally by their addition date rather than separately within each category. Updated the homepage navigation and sorting label.

11 October 2026

Sitewide UI Refresh v2.1

Extended the updated visual design to all tool profiles, categories, the Security AI directory, Submit a Tool, About, training and certification pages, and the changelog. Preserved the original brand, directory data, URLs, filters, and GitHub submission workflow.

2026-10-10

  • Added Promptfoo, an open-source framework for LLM evaluations, AI red teaming and security testing of LLM applications. Classified as Security-Native AI.
  • Improved the homepage headline and directory search wording while preserving the established logo, colours and layout. Updated the Submit a Tool page and GitHub issue template with required AI classification, examples, clearer review expectations and submission guidance.
  • Introduced Security-Native AI and General-Purpose AI classifications for all 40 tools, with directory filters, card labels, tool-profile descriptions and search support. Security-native tools are purpose-built for cybersecurity; general-purpose tools can support security practitioners without being dedicated security products.

  • Added Pentest Swarm AI, an open-source, self-hosted agent swarm for autonomous web application and API pentesting, attack-chain exploration, vulnerability validation and evidence-backed reporting. Listed as Experimental (alpha) based on the project's own status.
