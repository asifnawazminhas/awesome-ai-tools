Editorial Policy

Selection

Tools are included when they provide a distinct and useful AI capability.

Verification

Entries are checked against official websites or source repositories. Each tool has a last verified date and maintenance status.

Open Source

Open Source indicates a public source repository and published open-source terms.

Featured

Featured status reflects prominence, usefulness or distinct capability. Inclusion is not an endorsement.

Corrections

Visitors can submit corrections or tools through the GitHub issue template.

Privacy

Favorites and popularity counters are stored locally in the browser. Analytics support is disabled by default.

Directory focus

AI Security first

Awesome AI Tools now focuses on AI security. The catalogue includes Security Native tools built for cybersecurity or AI security, plus a smaller set of General AI for Security tools with practical value in authorised security research, code analysis, scripting, documentation, local/private workflows and model research.
